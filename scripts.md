# Cavalry Scripts

## Keyframes

- [Align Keyframes](scripts/align-keyframes.md) - A toolbar with various keyframe alignment tools
- [Keyframe Looping](scripts/keyframe-looping.md) - A toolbar to quickly set looping on an animation curve
- [Magic Easing](scripts/magic-easing.md) - A helper tool to work with built-in Magic Easing or to save and reuse your own Custom expressions

## Layers

- [Align](scripts/align.md) - Align and distribute Shapes, Groups, or drawable Layers (e.g. Null, Falloff)
- [Move & Duplicate](scripts/move-and-duplicate.md) - Move selected Shape Layers or Path's Points by a specified angle and distance
- [Set Pivot](scripts/set-pivot.md) - Sets the Pivot based on the Shape's bounding box without moving the Layer
- [Shape Tools](scripts/shape-tools.md) - The Cavalry script with various Shape tools
- [String Array](scripts/string-array.md) - Splits the entered text into sub-strings by the selected delimiter and creates a String Array from them
- [Stroke Width](scripts/stroke-width.md) - Offsets or multiplies the Stroke Width of the Shapes
- [Swap Color](scripts/swap-color.md) - Search the Scene for a specific color and replace it with another one

## Attributes

- [Attribute Tools](scripts/attribute-tools.md) - Various tools to work with Attributes and connections
- [Attribute Expression](scripts/attribute-expression.md) - Apply an Attribute Expression to multiple selected Attributes at once
- [Attribute Renamer](scripts/attribute-renamer.md) - This script helps you rename multiple Attributes at once

## Workspace

- [History](scripts/history.md) - A small button to go back to the previous active Compositions
- [Storage Slots](scripts/storage-slots.md) - This script allows you to preserve Layer or Keyframe selection and restore it later
- [Note](scripts/note.md) - Script to display a text note in the Cavalry interface
- [Palette](scripts/palette.md) - The mini color palette for Cavalry
- [Version Toolbar](scripts/version-toolbar.md) - A mini toolbar to show the Cavalry version

## Miscellaneous

- [Mini Scripts](scripts/mini-scripts.md) - Small scripts that run without a graphical user interface
- [Sublime Text to Cavalry](scripts/sublime-text-to-cavalry.md) - Use Sublime Text as an external script editor for Cavalry
