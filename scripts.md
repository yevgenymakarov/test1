# Cavalry Scripts

## Keyframes

- [Align Keyframes](/) - A toolbar with various keyframe alignment tools
- [Keyframe Looping](/) - A toolbar to quickly set looping on an animation curve
- [Magic Easing](/) - A helper tool to work with built-in Magic Easing or to save and reuse your own Custom expressions

## Layers

- [Align](/) - Align and distribute Shapes, Groups, or drawable Layers (e.g. Null, Falloff)
- [Move & Duplicate](/) - Move selected Shape Layers or Path's Points by a specified angle and distance
- [Set Pivot](/) - Sets the Pivot based on the Shape's bounding box without moving the Layer
- [Shape Tools](/) - The Cavalry script with various Shape tools
- [String Array](/) - Splits the entered text into sub-strings by the selected delimiter and creates a String Array from them
- [Stroke Width](/) - Offsets or multiplies the Stroke Width of the Shapes
- [Swap Color](/) - Search the Scene for a specific color and replace it with another one

## Attributes

- [Attribute Tools](/) - Various tools to work with Attributes and connections
- [Attribute Expression](/) - Apply an Attribute Expression to multiple selected Attributes at once
- [Attribute Renamer](/) - This script helps you rename multiple Attributes at once

## Workspace

- [History](/) - A small button to go back to the previous active Compositions
- [Storage Slots](/) - This script allows you to preserve Layer or Keyframe selection and restore it later
- [Note](/) - Script to display a text note in the Cavalry interface
- [Palette](/) - The mini color palette for Cavalry
- [Version Toolbar](/) - A mini toolbar to show the Cavalry version

## Miscellaneous

- [Mini Scripts](/) - Small scripts that run without a graphical user interface
- [Sublime Text to Cavalry](/) - Use Sublime Text as an external script editor for Cavalry
