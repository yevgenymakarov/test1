# Cavalry Plugins

## Shapes

- [Chevron Shape](/) - Create a chevron shape
- [Cube Shape](/) - Create a cube in orthographic projection
- [Cylinder Shape](/) - Create a cylinder in orthographic projection
- [Square Star](/) - A star-like shape with square points
- [Wireframe Sphere](/) - A sphere constructed from lines

## Deformers

- [Mirror Deformer](/) - Reverse a Shape along a center line to create a reflection
- [Path Transform](/) - Apply transformations to Shape's path while maintaining the stroke width
- [Path Visualizer](/) - Draw the points and handles of a bézier curve
- [Pucker and Bloat](/) - Push the Shape's points inward or pull them outward while curving the segments
- [Rolling Motion](/) - Rotates a Shape and moves it, simulating rolling along a flat surface
- [Wave Warp](/) - Apply the wave effect traveling across a Shape
- [Wiggle](/) - Apply the Wiggle effect to a Shape

## Utilities

- [Split String](/) - Splits the entered string (text) into sub-strings by the selected delimiter

## Filters

- [ASC-CDL Color Correction](/) - Adjust the colors using Slope, Offset, and Power transfer functions
- [Channel Mixer](/) - Replace the red, green, blue, and alpha channels with mixed values of the original channels
- [Linear Brightness and Contrast](/) - Adjust the brightness and contrast of a layer using linear transfer functions
