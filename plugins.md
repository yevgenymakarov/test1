# Cavalry Plugins

## Shapes

- [Chevron Shape](plugins/chevron-shape.md) - Create a chevron shape
- [Cube Shape](plugins/cube-shape.md) - Create a cube in orthographic projection
- [Cylinder Shape](plugins/cylinder-shape.md) - Create a cylinder in orthographic projection
- [Square Star](plugins/square-star-shape.md) - A star-like shape with square points
- [Wireframe Sphere](plugins/wireframe-sphere-shape.md) - A sphere constructed from lines

## Deformers

- [Mirror Deformer](plugins/mirror-deformer.md) - Reverse a Shape along a center line to create a reflection
- [Path Transform](plugins/path-transform-deformer.md) - Apply transformations to Shape's path while maintaining the stroke width
- [Path Visualizer](plugins/path-visualizer-deformer.md) - Draw the points and handles of a bézier curve
- [Pucker and Bloat](plugins/pucker-and-bloat-deformer.md) - Push the Shape's points inward or pull them outward while curving the segments
- [Rolling Motion](plugins/rolling-motion-deformer.md) - Rotates a Shape and moves it, simulating rolling along a flat surface
- [Wave Warp](plugins/wave-warp-deformer.md) - Apply the wave effect traveling across a Shape
- [Wiggle](plugins/wiggle-deformer.md) - Apply the Wiggle effect to a Shape

## Utilities

- [Split String](plugins/split-string-utility.md) - Splits the entered string (text) into sub-strings by the selected delimiter

## Filters

- [ASC-CDL Color Correction](plugins/asc-cdl-color-correction-filter.md) - Adjust the colors using Slope, Offset, and Power transfer functions
- [Channel Mixer](plugins/channel-mixer-filter.md) - Replace the red, green, blue, and alpha channels with mixed values of the original channels
- [Linear Brightness and Contrast](plugins/linear-brightness-and-contrast-filter.md) - Adjust the brightness and contrast of a layer using linear transfer functions
