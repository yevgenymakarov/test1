# String Array

> Version 1.1.0
> Supports Cavalry 2.6.0 and later.
> **[Buy Now](https://app.lava.top/products/809aa755-80a3-48ef-b88b-e4b939fcd510 "Go to the store")**
{: .py-3 .bg-gray .rounded-2 }

This script splits the entered text into sub-strings by the selected delimiter and creates a String Array from these sub-strings.

<img width="600" alt="String Array" src="../images/string-array.png">

## User Manual

**Source Text** - Enter the text to be split into an array.

**Mode** - Select a method for splitting the source text. Separation by characters, words, newlines, commas or tabs is available.

**Skip Empty** - Do not add blank strings to the final array.

**Show Preview** - Show a preview of the result array in the script interface.

**Live Update** - Automatically update the selected String Array Layers.

**Apply** - Update the selected String Array Layers. To create a new String Array Layer, hold <kbd>Option/Alt</kbd> while clicking this button.

### Context menu items

**Create a New Layer** - Create a new String Array Layer.

**Update Selected Layers** - Update the selected String Array Layers.

**Presets** - Built-in presets:

- Alphabet Characters (hold <kbd>Option/Alt</kbd> to create a lowercase alphabet)
- Days of the Week
- Months of the Year
