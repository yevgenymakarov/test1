# Attribute Renamer

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Attribute.Renamer.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This script helps you rename multiple Attributes at once.

<img width="600" alt="Attribute Renamer" src="../images/attribute-renamer.png">

## User Manual

The script displays input fields for renaming the selected Attributes. The context menu includes an option to convert case, such as Snake Case or Camel Case. An empty string resets the name to its default.
