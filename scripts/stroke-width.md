# Stroke Width

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Stroke.Width.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This script offsets or multiplies the Stroke Width of the Shapes.

<img width="600" alt="Stroke Width" src="../images/stroke-width-offset.png">

## User Manual

**Offset Value** - Stroke Width offset or multiply value.

**Multiply** - Multiply the stroke Width instead of adding to it.

**Apply** - Apply the stroke Width offset.
