# Set Pivot

> Version 1.1.0
> Supports Cavalry 2.6.0 and later.
> **[Buy Now](https://app.lava.top/products/ed23208a-8318-48c9-9be6-69157c9c812f "Go to the store")**
{: .py-3 .bg-gray .rounded-2 }

This script allows you to set the Pivot based on the Shape's bounding box without moving the Layer.

<img width="600" alt="Set Pivot" src="../images/set-pivot.png">

## User Manual

**Nine-point widget** - Set the Pivot to one of the nine points of the Shape's bounding box. Hold down <kbd>Option/Alt</kbd> to use the overall bounding box of all selected Shapes. Hold down <kbd>Cmd/Ctrl</kbd> to include child Shapes while calculating the bounding box.

### Context menu items

**Set to Bounding Box** - Set the Pivot to one of the nine points of the Shape's bounding box.

**Pivot of Last Selected Shape** - Get the relative Pivot position of the last selected Shape and set it for all selected Shapes. Hold down <kbd>Option/Alt</kbd> to use the absolute Pivot position.

**Point of Editable Path** - Set the Pivot to the absolute position of the selected Point of the Editable Shape.
