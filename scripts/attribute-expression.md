# Attribute Expression

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Attribute.Expression.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This script helps you apply an Attribute Expression to multiple selected Attributes at once.

<img width="600" alt="Attribute Expression" src="../images/attribute-expression.png">

## User Manual

**Apply** - Add an Attribute Expression to the selected Attributes.

**Clear** - Remove the Attribute Expression for the selected Attributes.

By clicking on the XYZ icons, you can mute this component to prevent it from updating.

### Context menu items

**Add Expression** - Add an Attribute Expression to the selected Attributes.

**Remove Expression** - Remove the Attribute Expression for the selected Attributes.

**Get Expression** - Retrieve the Attribute Expression from the last selected Attribute.
