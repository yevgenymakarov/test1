# Version Toolbar

> Version 1.0.0
> Supports Cavalry 2.4.3 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Version.Toolbar.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

A mini toolbar to show the Cavalry version, which can be useful when using different versions of Cavalry at the same time.

<img width="600" alt="Version Toolbar" src="../images/version-toolbar.png">

## User Manual

### Known Issues

Due to certain limitations in Cavalry, in some cases you won't be able to dock toolbar panels side by side. To work around this, temporarily dock any script with a tab, or simply use the Align window, and then dock the Version Toolbar underneath it. After that, remove the temporary window.
