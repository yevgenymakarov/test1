# Note

> Version 1.0.0
> Supports Cavalry 2.4.3 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Note.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

Script to display a text note in the Cavalry interface.

<img width="600" alt="Note" src="../images/note.png">

## User Manual

This is just a small text field for notes, allowing you to save values or text without leaving the Cavalry interface. A slider for adjusting the text size appears when you hover over it with the cursor. The note is saved in the Cavalry preferences.
