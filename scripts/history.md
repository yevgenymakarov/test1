# History

> Version 1.1.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/History.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This script allows you to go back to the previous active Compositions.

<img width="600" alt="History" src="../images/history.png">

## User Manual

**Back** - Go back to the previous Composition.

**Forward** - Go to the next Composition.

### Context menu items

**Recent** - Open any of the last ten active Compositions.

**Back** - Go back to the previous Composition.

**Forward** - Go to the next Composition.

**Toolbar** - Switch between the Mini and Regular size interface.

### Known limitations

The history is reset when Workspace is changed.
