# Align Keyframes

> Version 1.1.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Align.Keyframes.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

The Cavalry script with various keyframe alignment tools.

<img width="600" alt="Align Keyframes" src="../images/align-keyframes.png">

## User Manual

**Align Keybars** - Align the selected Keyframes (the group on each attribute) to each other.

- Left
- Center
- Right

**Align to Playhead** - Align the selected Keyframes (the group on each attribute) with the playhead.

- Left
- Right

**Align Keyframes to Playhead** - Align the closest (to the playhead) of the selected Keyframes with the playhead.

**Align Keyframe Values** - Align keyframe values to the highest, average, or lowest value of the selected Keyframes.

- Highest
- Middle
- Lowest
- Average

### Context menu items

**Round Values** - Round the values of selected Keyframes to integers.
