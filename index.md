# Scripts and Plugins for Cavalry

## Plugins

Third party Deformers, Shapes, or Filters appearing as native Layers in Cavalry.

- [Rolling Motion](plugins/rolling-motion-deformer.md) - Rotates a Shape and moves it, simulating rolling along a flat surface
- [Path Visualizer](plugins/path-visualizer-deformer.md) - Draw the points and handles of a bézier curve
- [Cube Shape](plugins/cube-shape.md) - Create a cube in orthographic projection
- [Wireframe Sphere](plugins/wireframe-sphere-shape.md) - Create a sphere constructed from lines
- [Split String](plugins/split-string-utility.md) - Splits the entered text into sub-strings by the selected delimiter

[More plugins...](plugins.md)
{: .ml-3}

## Scripts

Tools with a user interface, which can be docked and saved as part of a Workspace.

- [Set Pivot](scripts/set-pivot.md) - Set the Pivot based on the Shape's bounding box
- [Swap Color](scripts/swap-color.md) - Search the Scene for a specific color and replace it with another one
- [Palette](scripts/palette.md) - The mini color palette for Cavalry
- [Attribute Tools](scripts/attribute-tools.md) - A toolbar script with various Attribute tools
- [Shape Tools](scripts/shape-tools.md) - A mini toolbar with various Shape tools

[More scripts...](scripts.md)
